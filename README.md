# MiCine 🎬

App personal para llevar registro de las películas y series que vi, con portadas, información, recomendaciones y sagas en orden (Marvel, Star Wars, Harry Potter y más).

**Abrir la app:** https://juanpiolmos2005-max.github.io/micine/

## Cómo usarla
1. Conseguí una clave gratuita en [themoviedb.org → Ajustes → API](https://www.themoviedb.org/settings/api).
2. Abrí la app y pegá la clave. Se guarda solo en tu navegador, nunca en este repositorio.
3. Tildá ✓ lo que ya viste, explorá sagas y mirá las recomendaciones en “Para vos”.

Tu lista se guarda en el navegador. Para pasarla a otro dispositivo usá **Mi lista → Copia de seguridad**.
